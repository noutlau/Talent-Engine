# Talent Engine — Frontend

Interface React 19 + Vite + Tailwind CSS 4 : formulaire de candidature et espace responsable.

```bash
npm install
npm run dev     # http://localhost:5173 — les appels /api sont relayés vers Laravel (http://127.0.0.1:8000)
```

Si l'API tourne sur un autre port : `VITE_API_TARGET=http://127.0.0.1:8001 npm run dev`.

Installation complète, architecture et choix techniques : voir le [README principal](../README.md).
